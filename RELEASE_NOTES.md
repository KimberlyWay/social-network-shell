Учебная оболочка социальной сети на Kotlin и XML для Android 5.0 и новее.

- Лента из трёх публикаций с локальными иллюстрациями.
- Поиск людей по имени и городу, добавление и удаление друзей.
- Демонстрационные входящие сообщения, ввод и локальное сохранение своих сообщений, «Избранное».
- Изменение имени, города и информации о себе.

Вложения: APK для установки на телефон и ZIP с исходниками для Android Studio. Подробная инструкция находится в README.

Работает без интернета и сервера. Сообщения не передаются другим людям. Данные хранятся локально в SharedPreferences; базы данных нет.

APK собран в GitHub Actions, Android Lint выполнен. Используется отладочная подпись: при несовпадении подписи с предыдущей установкой сначала удалите старое приложение. Удаление приложения также удалит его локальные данные. Запуск на реальном телефоне отдельно не проверялся.
